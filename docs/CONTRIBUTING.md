# Cómo contribuir

¡Gracias por querer mejorar el muestrario!

1. Forkea el repositorio
2. Crea una carpeta en /sections/ con el nombre de tu nueva sección (en kebab-case, ej: faq-section)
3. Agrega:
   - Un mockup claro (PNG o JPG, mínimo 1080x1080 para IG)
   - Versión mobile si es diferente
   - Un archivo description.md con:
     - Nombre
     - Descripción breve
     - Ubicación típica
     - Por qué es útil / opciones de personalización
4. Haz un Pull Request con título claro: "Add: Nueva sección FAQ"
5. ¡Listo! Si se aprueba, aparecerá en Instagram pronto y te mencionaremos.

Ideas de secciones nuevas: FAQ acordeón, Pricing Table, Team Grid, Newsletter Signup, Integración de Chatbot, etc.
