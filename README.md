# web-sections-catalog
Open-Source collaborative catalog of essential website sections and elements. Developers contribute mockups, descriptions, and ideas for headers, hero sectios, testimonials, footers, and more. Perfect for freelancers and agencies to show clients visual options and let them choose/customize the structure of their website. Updates reflected on Insta

https://www.instagram.com/web.sections.catalog

```
web-sections-catalog/
├── sections/                  # Carpeta principal con una subcarpeta por sección
│   ├── header/
│   │   ├── mockup.png         # Imagen principal (mockup)
│   │   ├── mockup-mobile.png  # Versión mobile (opcional)
│   │   └── description.md     # Descripción detallada
│   ├── hero-section/
│   │   ├── mockup.png
│   │   └── description.md
│   ├── about-us/
│   └── ... (una por cada elemento)
├── instagram-templates/       # Plantillas listas para IG (Canva, PSD o PNG)
│   ├── carousel-template.psd
│   └── post-template.png
├── docs/
│   ├── CONTRIBUTING.md        # Guía para contribuir (¡importante!)
│   └── README.md              # Descripción del proyecto
├── assets/                    # Imágenes generales, logos, etc.
└── generate-instagram.js      # Script opcional para automatizar
```
